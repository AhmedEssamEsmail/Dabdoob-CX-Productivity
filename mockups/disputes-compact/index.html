Disputes — compact + collapsible options

Three collapsed layouts for the “to decide” list; every row expands in place to show the agent's case, lost marks, escalation trail and the meeting-decision form. Rendered with the app's real stylesheets in dark theme — the rows really collapse, click them.

A Expandable stripOne line per dispute — chevron, score, agent, ticket/auditor/raised-by (truncates), status. Expansion drops a detail sheet under the row. Matches CTL option A. Open → B Header + case previewTwo lines per dispute: identity + status on top, a one-line preview of the agent's case below. Expand for the full case, lost marks and decision form. Matches CTL option B. Open → C Expandable mini cards2-column compact cards; opening one spans the full row width for details. Best scannability, slightly taller collapsed. Matches CTL option C.
