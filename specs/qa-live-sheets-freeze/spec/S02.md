# S02: shared/jobs/dbbook.ts — synthesize legacy tab grids from DB
Kind: package
ID: S02
Dispatch: NEVER

## Goal and contract
New `src/features/shared/jobs/dbbook.ts` produces the same `unknown[][]` grids (header row included, 1-based readers) that `fetchWorkbookTabs` returned — sourced entirely from DB tables/config so engines and `sheetBook()` stay untouched (DECISION option A). Public API:
```ts
export interface DbBookCtx { cfg: Cfg; sinceMs?: number; month?: string | null }
export function dbBookMonthForId_(id: string, cfg: Cfg): string | null   // reverse prodFileFor_
export async function dbBookTabCells_(tab: string, ctx: DbBookCtx): Promise<unknown[][]>
```
Every grid's row 1 is a placeholder header (positional readers skip it). Rows ascend in source order (ts_ms / row_n). `sinceMs`/`month` bound reads the way TABLE_BOUNDS bounds job preloads; a null/unmatched month on a month tab = superset window `sinceMs..now`. Missing tables are missingOk -> header-only grid (same as a sheet tab reading empty). Non-goals: changing engine readers, wave-2 upstreams (FD_AUX live feed), SheetBookLike wrapper (env.ts owns that in S03).

### Contract
Core: `dbBookMonthForId_(id,cfg)` scans `cfg.productivity_files` entries for value===id (first match) -> month key `yyyy-MM`; id equal to `productivity_fallback_id` or unmatched -> `null`. `dbBookTabCells_(tab, ctx)` dispatches on tab name (unknown tab -> throws). Window helper: `month` set -> `[tphHourMs_(month+'-01',0,dataTz), tphHourMs_(next month,0,dataTz))` on `ts_ms`; `month` null/absent -> `ts_ms >= ctx.sinceMs ?? 0`.
- `'Maqsam Calls'` (maqsam_calls, bound by window): 12-cell rows `['','','', ...maqsamCells_(r), K, L]` — K = `new Date(Date.parse(String(r.started_at)))` (a Date cell like the sheet's, so `prodDateKey_` yields the same calendar date; '' when unparseable); L = `Number(r.handling)` when finite else `(Number(r.duration)||0)/60` (the sheet's decimal-minutes handling time). Rows `order by ts_ms asc` — must match the sheet's append order that tail readers rely on.
- `'Freshchat'` (freshchat, sinceMs bound): rows = `freshchatCells_(r)` (7 cells).
- `'Activities'` (fd_activities, sinceMs bound): rows = `fdActivityCells_(r)` (10 cells).
Header rows: `['Agent Name','Start',...]`-style placeholders matching each tab's legacy labels — content is cosmetic (readers are positional) but MUST exist so `getLastRow()`/`prodReadCols_` header skip works.
Out of scope: the other five tabs (S02-02), env.ts wiring, SheetBookLike creation, any file outside the two listed.
