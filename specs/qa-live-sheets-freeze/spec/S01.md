- `src/features/shared/jobs/sheets.ts:80` | fetchWorkbookTabs — downstream consumer of this guard (S01-02)

### Contract
```ts
import 'server-only'
export class SheetsFreezeError extends Error { /* name='SheetsFreezeError', message names id+tab */ }
export interface SheetReadGateOpts {
  extraIds?: readonly string[]  // caller-resolved extra allowed workbook ids; tab 'Activities' only
  manualHct?: boolean           // caller is the manual "Sync roster from HCT now" path
  deferred?: boolean            // wave-1 grandfather: log [SHEETS_FREEZE_VIOLATION], allow
}
export function assertSheetReadAllowed_(spreadsheetId: string, tab: string, opts?: SheetReadGateOpts): void
```
Evaluation order (first match wins):
1. `id === '1sOFoYdrbKorQ0WOA6bgJT1ROpzPxq2N-7oWnjhsxm3w' && tab === 'qa_audits'` -> return.
2. `id === '1LtUZbF4fdlLIaQMCMgrY7xZbs2C4zAfLAqlEWbKvNEw' && tab === 'Sheet1' && opts?.manualHct` -> return.
3. `tab === 'Activities' && opts?.extraIds?.includes(id)` -> return.
4. `opts?.deferred` -> `console.error('[SHEETS_FREEZE_VIOLATION] ' + JSON.stringify({ spreadsheetId: id, tab }))`; return.
5. throw `new SheetsFreezeError('Sheets read frozen: ' + id + ' / ' + tab)`.
Export `SHEETS_FREEZE_QUALITY_ID` / `SHEETS_FREEZE_HCT_ID` consts for the literals.
Out of scope: caller edits, repo-scan test, env/dbbook (S02/S03), any cx-quality file.

### Actions
1. Write the module exactly per contract (literal ids, documented as mirror of engine.ts SPREADSHEETS.quality/.hct).
2. Test: allowlisted (a),(b),(c) pass silently — incl. `'Sheet1'` WITHOUT `manualHct` NOT passing silently.
3. Test: `deferred:true` calls `console.error` once with `[SHEETS_FREEZE_VIOLATION]` and does not throw (vi.spyOn).
4. Test: non-allowlisted (e.g. `'Queue Log'`, prod month tabs, `'Sheet1'` sans flag) throws SheetsFreezeError.
5. Test: `extraIds` scopes to tab `'Activities'` only (same id + `'Maqsam Calls'` still throws).
