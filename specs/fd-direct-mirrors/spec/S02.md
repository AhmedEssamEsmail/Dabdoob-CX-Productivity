## S02-01: fd_activities typed columns
Kind: mini
ID: S02-01
Parent: S02
Owner: supabase-expert
Depends: none
Criteria: PLAN #2
Skills: none
Budget: files=1; actions=4; changed_lines=35; minutes=5

### Goal
`fd_activities` gains the 9 readable cells as typed columns; `ts_ms` stays the
window-query column (now a copy of `performed_at`).

### Files
- Create: `supabase/migrations/20261113000003_fd_activities_columns.sql` | whole file

### Context
- Cell layout (`engine-live.ts:142-144`): 0 Performed At, 1 Ticket ID,
  2 Performer Name, 3 Performer Type, 4 Activity Type, 5 Field Changed,
  6 New Value, 7 Old Value, 8 Group; cell 9 unread.
- Existing shape: `20261101175759_mirror_tables.sql:12-19`.

### Contract
```sql
ALTER TABLE public.fd_activities
  ADD COLUMN IF NOT EXISTS performed_at timestamptz,
  ADD COLUMN IF NOT EXISTS ticket_id text,
  ADD COLUMN IF NOT EXISTS performer_name text,
  ADD COLUMN IF NOT EXISTS performer_type text,
  ADD COLUMN IF NOT EXISTS activity_type text,
  ADD COLUMN IF NOT EXISTS field_changed text,
  ADD COLUMN IF NOT EXISTS new_value text,
  ADD COLUMN IF NOT EXISTS old_value text,
  ADD COLUMN IF NOT EXISTS group_name text;
CREATE INDEX IF NOT EXISTS idx_fd_activities_ticket ON public.fd_activities(ticket_id);
```
All nullable (dual-write period), no defaults, header comment cites S02-01 +
that `cols` is dropped in S05-04.

### Actions
1. `npx supabase migration new fd_activities_columns`.
2. Write ALTERs + index + header comment.
3. Verify newest in name order.
4. tsc clean.

### Done when
- Migration file exists and orders last.

### Verify
- Run: `ls supabase/migrations | tail -3 && npx tsc --noEmit` -> exit 0

### Handoff
S03-03 writes these columns; S05-02 backfills them.
Write results/S02-01.md (<=10 lines); TL alone updates TRACKER.md.

## S02-02: maqsam_calls + freshchat typed columns

Owner: supabase-expert
Depends: none
Criteria: PLAN #2
Skills: none
Budget: files=1; actions=4; changed_lines=40; minutes=5

### Goal
`maqsam_calls` and `freshchat` gain typed columns matching their 7-cell
layouts (vendor-apis.ts:33-35, :56-59).

### Files
- Create: `supabase/migrations/20261113000004_maqsam_freshchat_columns.sql` | whole file

### Context
- `src/features/shared/jobs/vendor-apis.ts:33-35,56-59` — the two 7-cell
  layouts the columns mirror

### Contract
```sql
ALTER TABLE public.maqsam_calls
  ADD COLUMN IF NOT EXISTS started_at timestamptz,
  ADD COLUMN IF NOT EXISTS ended_at timestamptz,
  ADD COLUMN IF NOT EXISTS duration text,          -- 'H:MM:SS' display, verbatim cell
  ADD COLUMN IF NOT EXISTS agent_email text,
  ADD COLUMN IF NOT EXISTS state text,
  ADD COLUMN IF NOT EXISTS direction text,
  ADD COLUMN IF NOT EXISTS handling text;          -- fractional days, verbatim cell
CREATE INDEX IF NOT EXISTS idx_maqsam_calls_agent ON public.maqsam_calls(agent_email);

ALTER TABLE public.freshchat
  ADD COLUMN IF NOT EXISTS conversation_id text,
  ADD COLUMN IF NOT EXISTS initiated_at timestamptz,
  ADD COLUMN IF NOT EXISTS updated_at timestamptz,
  ADD COLUMN IF NOT EXISTS resolved_at timestamptz,
  ADD COLUMN IF NOT EXISTS status text,
  ADD COLUMN IF NOT EXISTS channel text,
  ADD COLUMN IF NOT EXISTS ref_key text;           -- '<convId>-<createdMs>' cell 2
CREATE INDEX IF NOT EXISTS idx_freshchat_conv ON public.freshchat(conversation_id);
```
`duration`/`handling` stay text — readers parse the exact display strings;
storing verbatim cells keeps adapter parity lossless. Nullable, no defaults.

### Actions
1. `npx supabase migration new maqsam_freshchat_columns`.
2. Write both ALTERs + indexes + header comment.
3. Verify newest in name order.
4. tsc clean.

### Done when

### Verify
- Run: `ls supabase/migrations | tail -3 && npx tsc --noEmit` -> exit 0

### Handoff

Write results/S02-02.md (<=10 lines); TL alone updates TRACKER.md.
