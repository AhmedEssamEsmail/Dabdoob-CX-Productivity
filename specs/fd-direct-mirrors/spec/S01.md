## S01-03: qe_fd_cache populate + 30-day prune inside qeReadTicketDetail_
Kind: mini
ID: S01-03
Parent: S01
Owner: data-engineer
Depends: S01-02
Criteria: PLAN #3
Skills: none
Budget: files=2; actions=5; changed_lines=70; minutes=10

### Goal
Each `qeReadTicketDetail_` call upserts the fetched ticket-detail rows into
`qe_fd_cache` (PK `id`, `cached_at = now`) and prunes rows older than
`QE_FD_CACHE_KEEP_DAYS` — the legacy Ticket-Detail-Cache semantics backed by
`tickets` instead of the FD API.

### Files
- Edit: `src/features/cx-quality/lib/engine-live.ts` | `qeReadTicketDetail_` (:267-290)
- Create: `tests/quality/qe-fd-cache.test.ts` | upsert shape + prune predicate unit test

### Context
- `qe_fd_cache` columns (`20261106202513_migration_hardening.sql:194-199`):
  `id` PK, `group_name`, `contact_type_1..3`, `subject`, `status`, `country`,
  `order_id`, `channel`, `source`, `created_at`, `cached_at`
- `QE_FD_CACHE_KEEP_DAYS = 30` (`engine.ts:23`)
- `db()` upsert pattern: `dqUpsertTickets_` in `freshdesk.ts:197-202`

### Contract
- After the index build, upsert each fetched detail row:
  `{id: <ticket_id>, group_name, contact_type_1..3, subject, status, country, order_id, channel, source, created_at, cached_at: <now ISO>}`
  `onConflict: 'id'`. Errors are logged to `refresh_log` (`fdLogRun_`-style)
  but do NOT fail the queue build.
- Prune: `DELETE WHERE cached_at < now() - 30 days`, batched with the upsert;
  same non-fatal error handling.
- No-op when `want` is empty.

### Actions
1. Add the upsert + prune inside `qeReadTicketDetail_` after the idx build.
2. Wrap in non-fatal error handling (build must not break on cache writes).
3. Write the unit test: row shape keys, `cached_at` freshness, prune filter.
4. tsc + vitest the new test file.
5. eslint `engine-live.ts` + the test file.

### Done when
- `npx tsc --noEmit` clean; `npx vitest run tests/quality/qe-fd-cache.test.ts` green
- A QE build leaves fresh `qe_fd_cache` rows for the read ticket ids

### Verify
- Run: `npx tsc --noEmit && npx vitest run tests/quality/qe-fd-cache.test.ts` -> exit 0

### Handoff
QE detail path complete; `qe_fd_cache` is live-populated.
Write results/S01-03.md (<=10 lines); TL alone updates TRACKER.md.
