- Edit: `src/features/cx-quality/lib/engine-live.ts` | `qeReadTouches_` select (:172-180)

### Context
- ISO timestamps convert back via `new Date(v).toISOString()`; `null` → `''`.
- `tlqCallsFromMirrorRows_` also reads `r.dedupe_key` (:340) — keep it in the
  select list.
- `qeReadTouches_` selects only `cols` today (:175) → selects the 9 typed cols
  + `ts_ms` (still used for `.gte/.lt/.order`).

### Contract
- `fdActivityCells_(r)` → `[iso(r.performed_at), r.ticket_id, r.performer_name, r.performer_type, r.activity_type, r.field_changed, r.new_value, r.old_value, r.group_name, '']`
- `maqsamCells_(r)` → `[iso(started_at), iso(ended_at), duration, agent_email, state, direction, handling]`
- `freshchatCells_(r)` → `[iso(initiated_at), status, ref_key, iso(updated_at), iso(resolved_at), channel, conversation_id]`
- Null/blank → `''` exactly (matching how cells were stored).
- Selects replace `cols` with the typed column list; `.map(adapter)` produces
  the same `Row` shape readers consume (`{...r, cols: cells}`).

### Actions

2. `tlqueue.ts`: `maqsamRows`/`fdActivityRows` select typed cols and map rows
   through the adapter into `{dedupe_key, ts_ms, cols}`.
3. `engine-live.ts`: select the 9 fd cols + `ts_ms`; `.cols` per row via
   `fdActivityCells_`.
4. tsc + run the golden `queue-tlqueue` suite.
5. eslint touched files.
