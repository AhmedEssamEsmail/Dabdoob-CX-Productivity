### Goal
`migration/backfill-mirror-columns.ts` parses `cols` → the S02 typed columns
for all surviving rows in the three mirrors; resumable by `id` (checkpoint in

- Create: `migration/backfill-mirror-columns.ts` | whole file
- Create: `tests/jobs/mirror-cells.test.ts` | adapter round-trip (cells→row→cells identity) — reuses S04-01's `mirror-cells.ts` parsing rules

### Context
- Timestamp cells are display strings per table (fd: `activity_local_tz`
  MM-dd-yyyy; maqsam/freshchat: ISO) — parse to instant for `*_at`, keep the
  display string out of typed cols except verbatim text fields
  (`duration`, `handling`, `ref_key`, `status`, `channel`).
- `readAllPaged` id-asc pattern: `tlqueue.ts:610` usage + `tests/perf` helper.
- ~700k rows pre-purge; expect ~200k after S05-01.

### Contract
- `--dry`: per-table counts of rows with `cols IS NOT NULL AND <first typed col> IS NULL`, plus a 10-row sample diff preview.
- `--write`: paged updates (`UPDATE … SET <typed> WHERE id BETWEEN`), checkpoint key `backfill_mirror_cols_<table>` so re-runs resume; per-table updated counts + refresh_log row.
- Rows whose `cols` won't parse: count as `skipped`, leave typed cols NULL (adapter emits `''` — same as a blank cell).
- Test: a stored row round-trips through cells→typed→cells identically.

5. `--dry` verify.

### Done when
