## Goal and contract
`getQaScoresPage`, `getQaAnalyticsPage` and `getQaAnalyticsAudits` gain a
trailing `active` arg ('active' | 'all'; anything but 'all' = active mode, so
active-only is the default). In active mode the server narrows `qa_audits`
(and `qa_ctls` for analytics) by `agent_email ∈ activeSet` BEFORE the pure
builders run, so every aggregate/table/drill reflects active agents only.
`activeSet` = dq_hct emails with ANY row passing `dqHctActive_`
(`@/features/cx-hub/lib/roster`), normEmail'd. `qaActiveEmails_()` returns
`null` when dq_hct is missing/empty or yields no actives — callers then run
unfiltered (never empty the pages). `qaActiveKeep_(key, set)` keeps blank and
non-`@` keys ('(no lead)' sentinels); drops emails not in the set. Cache keys
gain a `':act'` suffix; payload shape unchanged. Non-goals: no schema/RLS
changes; `qaAnalytics_`/`qaScoresRange_`/`qaDrill_` untouched;
`qaQuotaAgents_`/`roster.active` sync unchanged; no new deps.

- New in server.ts (closure style, `/** name verbatim: ... */` comment like siblings):
  ```ts
  /** qaActiveEmails_: normEmail'd dq_hct emails with ANY row passing dqHctActive_; null = store missing/empty (never empty the pages). */
  async function qaActiveEmails_(): Promise<Set<string> | null> {
    const hct = await readStore('dq_hct')
    if (!hct.exists || !(hct.rows || []).length) return null
    const act = new Set<string>()
    hct.rows.forEach((r) => {
      if (!dqHctActive_(r)) return
      const e = normEmail(r.email)
      if (e) act.add(e)
    })
    return act.size ? act : null
  }
  /** qaActiveKeep_: person-key keep rule — blank and non-'@' keys ('(no lead)') stay; emails must be in the active set. */
  function qaActiveKeep_(key: unknown, act: Set<string>): boolean {
    const e = normEmail(key)
    return e.indexOf('@') === -1 || act.has(e)
  }
  ```
- `null` active set ALWAYS means "no filtering" downstream — existing tests/golden fakes seed no readable dq_hct.
Out of scope: `dqCleanEmail_`, `dqRosterFromHct_`, sync logic, the three getter signatures (later leaves), any other payload field.
