# S02: "Active only / All users" Seg controls on /quality-analytics and /quality-scores
Kind: package
ID: S02
Dispatch: NEVER

## Goal and contract
Each page gets a `Seg` in its filter row, default "Active only". Toggling
changes the page's request scope and refetches through the `P.*` contract
(S01-05); the already-filtered payload needs no client-side filtering. On
/quality-scores the choice persists in the URL hash as `act=all` (absent =
active, like `basis`). Non-goals: no visual redesign, no client-side row
filtering, no other pages, no localStorage.
