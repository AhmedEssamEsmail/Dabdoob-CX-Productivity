### Goal
Publish the shared predicates: a position-derived `dqTitleLevel_` (with role fallback) used by org features, and the exact `isCxAgent_` used by headcount numbers — plus `titleLevel` on every `DirectoryPerson`.

### Files
- Edit: `src/features/shared/platform/identity.ts` | new helpers near normEmail (:28), DirectoryPerson interface (:170-177), pwDirectory body (:194-251)
- Create: `tests/platform/directory-title.test.ts` | focused unit tests for the helpers only

### Context
- `src/features/shared/platform/identity.ts:194-252` | `pwDirectory` builds `by`, `managerOf`, `agentsOf`, `tls` — org semantics move from `role` to `titleLevel`
- `src/features/shared/platform/identity.ts:170-177` | `DirectoryPerson` shape
- DECISION.md §Design | `dqTitleLevel_`: 'tl' if `/team\s*lead(er)?/i`, 'manager' if `/manager|head of/i`, else 'agent'; **fallback to `role` when position is blank** (backfill may not have run yet)
- PLAN research | roster `position` populates from HCT verbatim, e.g. `Customer Experience Agent`

### Contract
- `export const CX_AGENT_POSITION = 'Customer Experience Agent'`
- `export function isCxAgent_(p: { active?: unknown; position?: unknown } | null | undefined): boolean` — `p.active` truthy-or-'true' AND `String(p.position||'').trim() === CX_AGENT_POSITION` (exact match, case-sensitive per DECISION Option A).
- `export function dqTitleLevel_(position: unknown, role: string): 'agent'|'tl'|'manager'` — position regexes first; blank position → role fallback: `role==='tl'`→'tl', `role==='admin'`→'manager', else 'agent'.
- `DirectoryPerson.titleLevel` set inside `pwDirectory` from `dqTitleLevel_(r.position, String(r.role||''))`.
- `managerOf`: agent-level→`tlEmail`; tl-level→`admins[0]||null`; manager/admin-level→`null` (a titled manager has no team lead in this model — keeps `pwIsManagerOf` sane).
- `agentsOf(tl)`: `titleLevel==='agent' && active && tlEmail===tl`.
- `tls()`: `titleLevel==='tl' && active`.
- `roleForEmail`/`requireRole`/`PlatformUser` unchanged — access stays on `role`.
Out of scope: any consumer re-pointing (S04), roster writes (S02), RLS/migrations.
