### Goal
`e2e/visual-baseline.spec.ts` captures a per-route screenshot at 375 and 1024
(chromium) and diffs it via `toHaveScreenshot`.

### Files
- Create: `e2e/visual-baseline.spec.ts` | parametrized over ROUTES x [375,1024]

### Context
- `e2e/routes.ts` | `ROUTES`/`RouteEntry` (P3-C1-01)
- `e2e/users.ts:41-70` | `login(page, email)`
- `e2e/page-contract.spec.ts` | ready-wait + login-per-role pattern (P3-C1-02)
- `playwright.config.ts:16-43` | projects incl. `mobile` (375) — spec pins viewport itself, skip non-chromium

### Contract
`for (const r of ROUTES) for (const w of [375,1024])`: login as
`E2E_USERS[r.user]`, goto, ready-wait (same helper shape as page-contract),
`expect(page).toHaveScreenshot(`${sanitize(r.path)}-${w}.png`,
{ maxDiffPixelRatio: 0.01 })`. `test.setTimeout(45000)`;
`test.skip(({browserName}) => browserName !== 'chromium', 'chromium baselines')`.
Volatile regions (`.cx-refresh [role=status]`, timestamps) go in the
screenshot `mask:` list — keep it generic, no per-route selectors.
Snapshot PNGs are emitted under `e2e/visual-baseline.spec.ts-snapshots/` by
`--update-snapshots`; record the count in results and never hand-edit them.
Out of scope: per-route masks beyond the generic list; CI workflow changes;
masking whole pages; touching playwright.config.ts.

### Actions
1. Spec scaffold: imports, `test.skip` for non-chromium, ready-wait helper,
   filename sanitizer (`/` -> `_`, leading `/` dropped, `/` -> `home`).
2. Parametrized loop: viewport -> login -> goto -> ready-wait -> screenshot.
3. First run: `npx playwright test e2e/visual-baseline.spec.ts
   --project=chromium --update-snapshots` -> log to
   `results/visual-baseline-run.log`; tail per OUTPUT-BUDGET.
4. Write `results/visual-baseline.md`: snapshot count, routes that needed a
   retry, and the update-snapshots regeneration command for future use.

### Done when
- Snapshot PNGs exist for every ROUTES entry at both widths (count ==
  ROUTES.length x 2 in results md)
- A re-run without `--update-snapshots` is green (same-session diff stable)

### Verify
- Run: `npx playwright test e2e/visual-baseline.spec.ts --project=chromium` -> all pass against committed baselines

### Handoff
C6 done; regeneration workflow documented in results/visual-baseline.md.
Write results/P3-C6-01.md (<=10 lines); TL alone updates TRACKER.md.
