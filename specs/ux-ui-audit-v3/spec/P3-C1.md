## Goal and contract
`e2e/page-contract.spec.ts` — parametrized over the live route inventory so a
new `src/app/**/page.tsx` is automatically covered (regression lock-in; a
hardcoded list would silently exempt new pages). Two artifacts:

- `e2e/routes.ts` (helper, no tests): exports `ROUTES: RouteEntry[]` built at
  spec-load time by walking `src/app` recursively (`readdirSync`, same
  `node:fs` convention as `e2e/aging-refresh-layout.spec.ts:2-6`). Route =
  parent dir of `page.tsx`, rel path, `\`->`/`, `''`->`'/'`. `EXCLUDED`:
  `[...slug]` catch-all (no canonical URL) and `auth/**` (unauthenticated
  flows). `RouteEntry = { path: string; user: 'admin'|'tl'|'agent';
  skipToolbar?: boolean; note?: string }` — `user` defaults `admin`;
  `ROLE_OVERRIDES` only where the route's feature lib `requireRole([...])`
  excludes `admin` (each page is a thin entry — grep the imported feature
  component's lib, e.g. `my-status` -> `cx-productivity`). `QUIRKS` map for
  per-route notes. Deterministic order (sort paths).
- `e2e/page-contract.spec.ts`: `for (const r of ROUTES) for (const w of [375,
  1024])` -> one test per route per width, `test.setTimeout(45000)` and
  `login(page, E2E_USERS[r.user])` per `e2e/users.ts` (seeded fixture users;
  every page is session-gated by `src/proxy.ts`). Ready-wait:
  `waitForLoadState('networkidle')`, then if `[aria-busy="true"]` exists wait
  `toHaveCount(0, {timeout:15000})` (convention from `my-status.spec.ts:15`).

Four assertions per test (PLAN C1, inputs+buttons folded into one):
1. no h-scroll: `document.documentElement.scrollWidth <= window.innerWidth`,
   re-asserted after the primary-action click.
2. toolbar stability: `.page-head .page-actions` (PageShell `aside` slot —
   `PageShell.tsx:42-50` renders `{aside}` inside `header.page-head`) bounding
   box x/y equal within 1px before/after clicking its first `button` (primary
   action; waitForTimeout(400) for status-text swap). If no `.page-actions`
   or no button -> skip with `test.info().annotations`, record route in
   results; routes listed `skipToolbar` in `QUIRKS` skip outright.
3. zero console errors: collect `console` type `error` + `pageerror` during
   load; filter `CONSOLE_ALLOWLIST: RegExp[]` (favicon 404, dev-overlay,
   transient Supabase token refresh noise); fail with offending texts.
4. accessible names: in-page `evaluate` over `input:not([type=hidden]),
   select, textarea` -> pass if `aria-label` non-empty OR `aria-labelledby`
   resolves to non-empty text OR `el.labels.length>0` OR `closest('label')`
   OR non-empty `title`; over `button` -> non-empty textContent OR
   aria-label OR aria-labelledby->text OR title. Report first 5 offender
   outerHTMLs in the failure message.

Non-goal: fixing pages that fail (Phase-1/2 scope); visual snapshots (P3-C6).

`src/app/**/page.tsx` minus `EXCLUDED`, each mapped to a fixture role.

### Files

### Contract
Export names/types exactly: `RouteEntry`, `ROUTES`, `EXCLUDED`, `ROLE_OVERRIDES`,
`QUIRKS` per package contract above. No Playwright imports (pure Node + types).
Out of scope: the spec file itself; editing users.ts; hardcoding the route list
(enumeration must be the `readdirSync` walk — new page.tsx files auto-appear).

### Actions
1. Write `RouteEntry` type + `EXCLUDED` (literal set: `[...slug]`, `auth`).
2. Implement recursive `readdirSync` walk of `resolve('src/app')`; filter

   overrides — more means the convention broke; stop with RESHARD_NEEDED.
4. Export `QUIRKS: Record<string,{skipToolbar?:boolean;note?:string}>` seeded
   empty; export `ROUTES` sorted by path.

### Goal

at 375 and 1024 px, logging in via the fixture matching `r.user`.

### Files
- Create: `e2e/page-contract.spec.ts` | parametrized spec only

### Context
- `e2e/routes.ts` | `ROUTES`, `RouteEntry` (from P3-C1-01)
- `e2e/users.ts:41-70` | `login(page, email)` retrying form login
- `e2e/my-status.spec.ts:5-16` | 45s timeout + `[aria-busy]` ready-wait convention

- `e2e/nav-collapse.spec.ts:12-19` | desktop viewport + booted-shell wait convention

### Contract
One `test(`${r.path} contract @${w}px``)` per (route, width) — flat loops, no
describe-per-route. Assertions exactly the four in the package contract.
`CONSOLE_ALLOWLIST` seeded: `/favicon/`, `/devtools/i`, `/Hydration/i`,
`/supabase.*(token|refresh)/i`. No waits on route-specific selectors beyond
the generic `[aria-busy]` rule. Skips via `QUIRKS`/`annotations`, never
`test.fixme` without a `note` string.
Out of scope: editing routes.ts/users.ts/playwright.config.ts; fixing any
failing page; adding a 5th assertion or extra viewports (PLAN fixes 375+1024).

### Actions
1. Imports + `ROUTES`/`E2E_USERS`/`login`; define `CONSOLE_ALLOWLIST` and the
   ready-wait helper (networkidle + `[aria-busy="true"]` -> count 0, 15s).
2. Loop `ROUTES` x `[375,1024]`; per test: setViewport, collect console/pageerror
   into an array, `login(page, E2E_USERS[r.user])`, `page.goto(r.path)`,
   ready-wait, `expect(page).toHaveURL(new RegExp(r.path === '/' ? '/$' : ...))`
   is NOT asserted — role-denied routes may render an error state, that's a
   real finding not a test bug.
3. Assertion 1: `scrollWidth <= innerWidth` via `page.evaluate`.
4. Assertion 2: `.page-head .page-actions` box before -> click first `button`
   -> 400ms -> box after equal within 1px; skip/annotate when absent; re-assert
   assertion 1 post-click.
5. Assertion 3: filtered console errors `toEqual([])` with joined offenders in
   the message.
6. Assertion 4: in-page evaluate returning offending elements (first 5
   outerHTMLs) for inputs/selects/textareas and buttons; `toEqual([])`.

### Done when
