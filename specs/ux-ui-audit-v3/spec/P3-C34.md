# P3-C34: eslint local-rule guards for new bug classes (PLAN C3 + C4)
Kind: package
ID: P3-C34
Dispatch: NEVER

## Goal and contract
Extend the inline `local` plugin in `eslint.config.mjs` with four statically
detectable Phase-1 class guards, following the file's own style: rule factory
objects (`loserRule`, `boundaryRule`, `localDefRule` at lines 5-72),
registration in `local.rules`, then per-glob config blocks with a comment
citing the class id and the warn backlog. **Warn-then-error strategy**: all
four ship `"warn"`; flip to `"error"` only after `npx eslint src` reports 0
warnings from them (burn-in = Phase-1 fixes merged), exactly like
`loser-classnames-warn` -> `loser-classnames-error` precedent. New rules:

| Rule | Class | Detection | Files glob |
|---|---|---|---|
| `local/no-transition-all` | B6 | any `Literal`/`TemplateElement` string matching `/transition\s*:\s*all/i` (reuse loserRule's visitor-keys walker, but visit from `Program` not only className) | `src/**/*.{ts,tsx}` warn |
| `local/no-hex-classname` | B5-lite | reuse `loserRule(re, skip, msg)` unchanged with `/#(?:[0-9a-fA-F]{3,8})\b/` — catches `bg-[#fff]`-style arbitrary values in className | `src/**/*.{ts,tsx}` warn |
| `local/no-raw-controls` | B3-lite (A3) | `JSXOpeningElement` whose lowercase `name.name` in `{input,select,textarea,button}` | `src/**/*.{ts,tsx}` warn, **off** for `src/features/shared/components/ui/**` via a trailing override block (precedent: env.ts/mirrors.ts `no-restricted-imports` off, lines 139-145) |
| `local/no-style-token-literals` | C4/B4 | `JSXAttribute name="style"` -> walk its value expression's strings for `/#(?:[0-9a-fA-F]{3,8})\b|\b\d+px\b|rgba?\(/i` | `src/features/**/*.{ts,tsx}` warn |

Caveat to record in a config comment: eslint sees no `.css` — B6/B5 in
stylesheets stay a Phase-1 sweep concern, not a rule.
Non-goals: autofixers; touching existing rules; eslint-plugin deps.

## P3-C34-01: four local rules at warn level
Kind: mini
ID: P3-C34-01
Parent: P3-C34
Owner: maintainer
Depends: none
Criteria: PLAN C3 + C4
Skills: none
Budget: files=1; actions=8; changed_lines=200; minutes=10

### Goal
`eslint.config.mjs` gains the four rules in the contract table, registered
`warn` under the stated globs, with per-block comments citing class ids and
any known-backlog files like the existing blocks do.

### Files
- Edit: `eslint.config.mjs` | new rule defs beside localDefRule + new config blocks before the closing `])`

### Context
- `eslint.config.mjs:14-36` | `loserRule` factory (walker + className visit) to reuse/variant
- `eslint.config.mjs:40-72` | `boundaryRule`/`localDefRule` plain-rule style + `files`/`plugins`/`rules` blocks
- `eslint.config.mjs:107-121` | warn-block commenting convention (id + backlog)
- `eslint.config.mjs:139-145` | per-path off-override precedent
- `specs/ux-ui-audit-v3/PLAN.md` C3/C4 rows | the four detections

### Contract
Only additive edits. Each rule gets a `meta.messages` id and a message that
names the class + canonical fix (e.g. "transition: all banned; list explicit
properties (B6)"). `no-raw-controls` off-block covers
`src/features/shared/components/ui/**` only — raw controls there are the
shared primitives themselves.
Out of scope: editing any other file; `"error"` severity (that's C34-02);
rules beyond the four; scanning `.css`/`.mdx`; new npm deps.

### Actions
1. Add `styleLiteralRule(re, message)` factory: like `loserRule` but the
   `visit` walker runs on `JSXAttribute` where `name.name === 'style'`.
2. Add `stringRule(re, message)` factory: same walker entered from `Program`
   so every `Literal`/`TemplateElement` string is tested (for B6).
3. Add `rawControlsRule`: `JSXOpeningElement` visitor, lowercase-name check
   against `{input,select,textarea,button}`.
4. Register all four in `local.rules`.
5. Add warn config block for `src/**/*.{ts,tsx}`: no-transition-all,
   no-hex-classname, no-raw-controls.
6. Add off-override block for `src/features/shared/components/ui/**`:
   `no-raw-controls` off.
7. Add warn block for `src/features/**/*.{ts,tsx}`:
   `no-style-token-literals`.
8. Self-check: `npx eslint src` exits 0 (warnings allowed), then create
   `tmp-lint-fixture.tsx` under `src/features/cx-hub/` violating each rule,
   confirm each warns, delete the file.

### Done when
- `npx eslint src` exit 0; each rule fires on its fixture (paste 1 sample
  warning per rule into results md)
- `npx eslint src/features/shared/components/ui` shows no raw-controls
  warnings
- No other file modified

### Verify
- Run: `npx eslint src 2>&1 | tail -20` -> exits 0; warning counts for the
  four rules recorded as the burn-in baseline

### Handoff
Warning baseline in results/P3-C34-01.md is C34-02's burn-in reference.
Write results/P3-C34-01.md (<=10 lines); TL alone updates TRACKER.md.
