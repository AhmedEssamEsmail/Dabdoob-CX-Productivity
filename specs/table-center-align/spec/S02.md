# S02: Markup audit — tag numeric `<td>`s with `cx-num` across all 34 table files
Kind: package
ID: S02
Dispatch: NEVER

## Goal and contract
In every `.tsx` file containing `<table` markup, each `<td>` whose rendered content is a numeral/percentage/count/fraction (`0`, `85%`, `19 of 20`, chips/badges holding those) must carry a class that centers it once S01 lands. Canonical class: **`cx-num`** (append to existing className, never replace). Cells already carrying `.cx-num`, `.num`, `.cx-num-col`, or another centered cell class (`.hm-c`, `.qa-cov__cell`, `.qa-cov__ctr`, `.qa-cov__day`, `.tph-hg__cell`, `.hm-gtotal td` context) need no edit — confirm and move on.

Shared audit rules for EVERY leaf (contract, do not rediscover):
- NEVER touch: `thead th` text (headers center via CSS only — exception: add `className` to `SortTh`/`<th>` ONLY if the header labels a numeric column AND the family's CSS keys off the cell class, e.g. `.qa-cov__ctr`; report these in results), `tbody th`, `th[scope=row]`/row labels, `.cx-rowhead`, `.qa-cov__name`, `.sch-sticky`, `.cx-groupbreak` rows, sticky first columns, `.trk-num`, `.hm-num` inputs, `.qa-w` inputs, any `<input>`/`<select>` cell, text-only cells, action/button/link-only cells.
- Report (in results/<id>.md, do NOT fix): `thead th` missing `scope="col"`, ambiguous cells (mixed text+number), tables whose numeric cells cannot be class-tagged without refactor.
- `colSpan` empty-state cells (`"No queues…"`) are text — skip.
- Verbatim-port style: minimal diff, no reformatting, keep existing class order (append `cx-num` last).
