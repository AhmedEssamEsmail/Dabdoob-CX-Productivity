### Context

### Contract
Assertions required:
1. `cx-kit.css` contains `thead tr th` + `text-align: center` in one rule covering `.cx-table` and bare `table`, and a `:is(td, tbody th):is(.cx-num, .num, .cx-num-col)`-style rule with `text-align: center`; `.cx-num-col` no longer declares `end`.
2. Each of `desk.css`, `people.css`, `queue.css`, `quality.css`, `refresh.css`: no surviving selector that sets `text-align:start|end` on `thead th` (regex on the file text); `quality.css` `.num` rule declares `center`.
3. Markup smoke (one component, cheap): render `WeekCoverage` per the qa-cov-center pattern and assert `class="cx-num qa-cov__ctr"` still renders (proves the class contract S02 relies on).
4. Row-label guard: `refresh.css` still contains `.cx-groupbreak th` `text-align:start`; `queue.css` `.sch-sticky` still `start !important`.
Out of scope: pixel/visual assertions, e2e, rendering pages with heavy data deps, asserting all 34 files.

### Actions
1. Create the test file with CSS-source assertions (read the 6 CSS files via `node:fs` + `node:path` from repo root).
2. Add the `WeekCoverage` renderToString markup check copied from `tests/quality/qa-cov-center.test.tsx` (reuse ROW/DATA constants).
3. Add the two row-label guard assertions (`.cx-groupbreak`, `.sch-sticky`).
