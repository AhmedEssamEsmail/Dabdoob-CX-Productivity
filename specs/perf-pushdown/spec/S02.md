## Goal and contract
Publish `readAllPaged` — the PK-ordered `.range` pager every truncation fix reuses —
and make unbounded `readRows` calls return `count(*)` rows instead of silently
stopping at PostgREST max-rows. Contract:

```ts
readAllPaged(name: string, opts?: {
  pk?: string                 // default 'id', else PK_OVERRIDES[name]
  pageSize?: number           // default 1000
  columns?: string            // default '*'
  build?: (q: T) => T         // caller filters applied before ordering/paging
}): Promise<Record<string, unknown>[]>
```
Orders by pk asc, pages `.range(from, from+pageSize-1)` until a short page, throws
`Error(error.message)` on failure — same surface as `readRows`. Non-goal: callers
migrate in their own leaves; bounded `readRows` calls keep the single-shot path.
