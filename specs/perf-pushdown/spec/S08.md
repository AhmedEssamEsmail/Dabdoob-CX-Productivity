Kind: package
ID: S08

## Goal and contract
Push the predicates the quality endpoints already apply in JS into SQL via
`qaRowsWhere_`, and group the sequential independent reads into `Promise.all`
(P-09). One call site per leaf (PLAN convention); every leaf KEEPS the in-memory
filter as a second guard — pushed predicates must be strict supersets of what JS
accepts. All leaves run serially (same file; chain S04-02 -> S08-01..12 -> S09-01).
Shared test file `tests/perf/qa-pushdown.test.ts` is created by S08-01 and extended
by each leaf (serial anyway). Each leaf records its new query + expected index in
results for the perf-gate EXPLAIN pass. Non-goals: all other `qaRows_`/`qaRowBy_`
sites not listed, `qaUpsertIn_` (S09), UI.
