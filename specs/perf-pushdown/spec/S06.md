## Goal and contract
`/api/prod/analytics` reads only the columns the analytics layer consumes,
date-bounds `prod_window_hist`, uses `configAll()` + `pwDirectory()` (P-21 part —
this file is single-writer here), and caches the computed `out` object for 120 s
under a per-user key. Response `out` stays field-identical except `cached` flag.

Out of scope: SQL view/RPC roll-up (audit P-02(d) "later"), other routes, `prodAnalytics_` internals.
