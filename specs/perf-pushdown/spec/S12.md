### Goal

- `docs/PERFORMANCE_PLAN.md:80-83` | P-12 fix; `vercel.json` 48 daily runs

### Contract
Both loaders route through `readAllPaged(name, { build })` where `build` applies the
bound map: `TABLE_BOUNDS: Record<string,{col:string}>` next to the loaders —
`prod_intervals: date` (existing), `prod_flags: date`, `prod_daily_layers: date`,
`prod_tph_days: date`, `prod_tph_cases/touches/calls/tasks: date`, `tickets: created_at`.
Bound VALUE per table: `intervalBound` for `prod_intervals` (as today, incl.
`ensureIntervals` widening); for other tables the derived bound = the earliest date
the job fns read — verify each against the job fns (tph-jobs reads; `tables` from
the cron route). Where a safe bound can't be derived, leave the table unbounded and
record the exception (bound only what's verified — the `missingOk` error semantics
stay). `roster` preload (`readRows('roster')`) already pages via S02-01.
Out of scope: `flushWrites` (done), `applyOp` internals (S12-02), job fn code.

### Actions
1. Read `job-tph-hourly` `opts.tables` + the consuming job fns; write the bound map with a one-line justification per bound (results file).
2. Refactor both loaders to `readAllPaged` + bound map (share a small `loadTable(name)` helper inside the file).
3. `ensureIntervals` keeps its widening logic via `readAllPaged`.
4. Tests: mocked `db()` asserts each bound table gets `gte(col, bound)`; >1-page load concatenates; unbounded tables still fetch fully.
5. `npx tsc --noEmit` clean.

### Done when
- tests green; tsc clean; every preload read is paged; verified tables carry bounds
