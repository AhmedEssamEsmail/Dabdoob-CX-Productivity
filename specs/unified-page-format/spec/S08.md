## S08-01: `e2e/page-frame.spec.ts` — uniform head geometry across all routes
Kind: mini
ID: S08-01
Parent: S08
Owner: test-engineer
Depends: S03, S04, S05, S06, S07
Criteria: PLAN #3 (identical coordinates), #7 (doesn't break contract suite)
Skills: C:\Users\AHMED\.agents\skills\webapp-testing\SKILL.md
Budget: files=1; actions=6; changed_lines=230; minutes=10

### Goal
Every routed page renders title/sub/actions/toolbar/stats at identical coordinates (tolerance 2 px) at 1024 and 1440 px and stacks head → bar → stats → body at 375 px.

### Files
- Create: `e2e/page-frame.spec.ts` | the geometry spec

### Context
- `e2e/routes.ts` | `ROUTES` inventory + `RouteEntry`; reuse — add a local `FRAME_EXCLUDED = new Set(['/ecosystem'])` (bare `.eco3` chrome outside `.main`)
- `e2e/page-contract.spec.ts:53-60` | `ready(page)` settle helper + `hScrollPx` pattern to copy
- `e2e/users.ts` | `login(page, E2E_USERS[entry.user])` convention
- `docs/PAGE-FRAME.md` | slot names/DOM the assertions target (S01-05)

### Contract
For each `ROUTES` entry except `/ecosystem`: login as its fixture role, visit route, settle with the `ready()` pattern. Collect per route at 1024 and 1440 viewport: `.page-title` computed font-size/font-weight/line-height + `getBoundingClientRect().top/.left`; `.page-purpose` (if present) font-size; `.page-actions` (if present) right edge vs `.page-head` right edge; `.page-bar`/` .page-stats` (where present) top minus preceding-slot bottom gap. Assertions: h1 font metrics identical across all routes; h1 top/left within ±2 px across all routes; `.page-purpose` font-size identical; `.page-actions` right edge == `.page-head` right edge ±2 px; inter-slot gaps equal ±2 px among routes sharing the slot. At 375: no h-scroll (`scrollWidth - innerWidth <= 0`) and slot top offsets strictly ascending head < bar < stats < body where each exists. Role-denied/error-state routes: skip geometry, record in results (same convention as page-contract). Out of scope: editing `routes.ts`/`page-contract.spec.ts`, asserting `.stat` internals, pixel values vs a mock (cross-page equality only).

### Actions
1. Copy the `ready()`/`hScrollPx` helpers and `CONSOLE_ALLOWLIST` handling convention from page-contract.spec.ts.
2. Build the per-route measurement via `page.evaluate` (single evaluate returning the metric object).
3. Parametrize over `ROUTES.filter(r => !FRAME_EXCLUDED.has(r.path))` × `[1024, 1440]`.
4. Assert cross-page equality/tolerances per contract.
5. Add the 375 px stack-order + h-scroll test.
6. Run `npx playwright test e2e/page-frame.spec.ts` (PM dev server) and record exit + failures; tune only for genuinely exempt states (role-denied), never loosen tolerance.

### Done when
- Spec exists, covers every non-excluded route at both widths + 375 stack.
- `npx playwright test e2e/page-frame.spec.ts` exit 0 on the migrated tree.
- Role-denied skips documented in results.

### Verify
- Run: `npx playwright test e2e/page-frame.spec.ts --reporter=line` -> all pass (redirect heavy output to `specs/unified-page-format/logs/`; quote exit + bounded tail only).

### Handoff
Regression gate for the frame contract; runs in PM's `npm run test:e2e` gate.
Write results/S08-01.md (<=10 lines); TL alone updates TRACKER.md.

## S08-02: `e2e/nav-no-splash.spec.ts` — no boot splash on client navigation

### Goal
A spec clicks through the rail nav (incl. a throttled pass) and proves `.boot-splash` never becomes visible, `#app` never empties, `.rail` never unmounts, and the only wait cue is `.page-loading .spinner`.

### Files
- Create: `e2e/nav-no-splash.spec.ts` | the navigation spec

### Context
- `e2e/users.ts` | `login` + `E2E_USERS.admin` (admin sees the most nav links)
- `src/features/shared/components/shell/AppShell.tsx` | `.nav a` rail links, `data-pending` attr on pending link
- `specs/unified-page-format/DECISION.md:12-15` | root cause + fix being verified (`#app[data-booted]` latch, `loading.tsx`)
- `e2e/page-contract.spec.ts:53-56` | `ready()` settle pattern

### Contract
After `login`, install a `page.evaluate` MutationObserver on `document.body` recording `window.__splashSeen` when `.boot-splash` gains `visibility!=hidden`/`display!=none`, and `window.__appEmptied` when `#app` childElementCount hits 0. Test 1: collect `.nav a[href^="/"]` hrefs, click each in turn, wait for `data-pending` to clear / `ready()`; after the crawl assert `__splashSeen` falsy, `__appEmptied` falsy, `.rail` element handle identical across nav (`page.evaluateHandle` capture before/after or assert `.rail` `toBeVisible` continuously + `expect(__railMounts).toBe(1)` via a `data-*` probe), and `#app[data-booted]` still set. Test 2 (throttled): `page.context().setOffline` NOT — use CDP `Network.emulateNetworkConditions` Slow 3G + `Emulation.setCPUThrottlingRate` 4x on first 3 links; assert same invariants and that if `.page-loading` appears it resolves within budget. `prefers-reduced-motion` not required. Out of scope: measuring exact nav latency (perf gate watches this), cold-load splash assertions (out of scope per PLAN).

### Actions
1. Write observer-install + invariant helpers in the spec file.
2. Test 1: full nav crawl asserting the three invariants after every click.
3. Test 2: throttled first-three-links pass with the same assertions + `.page-loading`-only wait cue check.
4. Assert `.boot-splash` `toBeHidden()` at each settled state too.
5. Run `npx playwright test e2e/nav-no-splash.spec.ts` (PM dev server); record exit + failures.

### Done when
