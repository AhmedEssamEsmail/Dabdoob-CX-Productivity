Publish the ONE page-frame contract every migration leaf (S03–S07) relies on.

kicker → h1.page-title → p.page-purpose with `.page-actions` on the row end;
`.page-bar` (tools left, status right) renders only when `toolbar`/`status`
exists; `.page-stats` renders only when `stats` exists; `busy`/`error`/
`onRetry`/`id`/`className`/`children` semantics unchanged. Non-goals: page
internals, `.stat` card internals, removing legacy class names still in use.
